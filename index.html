Sobre o sistema

CRM Borges é um sistema 100% local de gestão financeira pessoal. Todos os dados são armazenados no seu navegador (localStorage) — nada é enviado para servidores externos, exceto consultas anônimas de cotações na API pública da B3 (brapi.dev).

Auto-save: cada lançamento é salvo instantaneamente.
Segurança: faça backups periódicos pelo botão de exportar no topo.
Tema: alterne entre modo claro e escuro no botão ao lado.
